# What is Express.js
Express.js is a fast, lightweight and flexible web application framwork for node.js.

It is used to build web server, REST APIs and backend application easily.

# KeY Features of Express.js
1. Fast and Lightweight: 
Helps build backend applications with less code.

2. Routing: 
Handles different HTTP requests such as GET, POST, PUT, and DELETE.

3. Middleware: 
Allows us to execute functions between receiving a request and sending a response.

4. REST API Development: 
Makes it easy to create APIs.

5. Database Integration: 
Can connect with MongoDB, MySQL, PostgreSQL, etc.

6. Error Handling:
Helps manage application errors.
